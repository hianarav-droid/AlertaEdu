A ideia

Tecnologia para perceber cedo. Pessoas para acolher.

O Presença Inteligente organiza registros de frequência, sinaliza mudanças e ajuda a equipe escolar a planejar apoio antes que as faltas se acumulem.

O que demonstra

  • Registro de frequência.
  • Indicadores e tendências.
  • Alertas preventivos por regras simples.
  • Registro de motivos relatados e ações de apoio.
  • Acompanhamento posterior.

Limites e responsabilidade

  • Não prevê o futuro nem diagnostica problemas pessoais.
  • Não deve punir ou expor estudantes.
  • Os alertas precisam de revisão humana.
  • Uma implantação real exigiria permissões por função, segurança e conformidade com a LGPD.
Protótipo para fins educacionais. Use apenas dados fictícios até que exista uma configuração de segurança adequada.
